# Retrieve signal/channel names

Get the names of the `signals` element of `eegUtils` objects.

## Usage

``` r
channel_names(.data)
```

## Arguments

- .data:

  `eegUtils object`

## Examples

``` r
channel_names(demo_epochs)
#>  [1] "A5"  "A13" "A21" "A29" "A31" "B5"  "B6"  "B8"  "B16" "B18" "B26"
```
