# Check consistency of event and timing tables

Check consistency of event and timing tables

## Usage

``` r
check_timings(.data, verbose = TRUE)

# S3 method for class 'eeg_data'
check_timings(.data, verbose = TRUE)

# S3 method for class 'eeg_epochs'
check_timings(.data, verbose = TRUE)
```

## Arguments

- verbose:

  Print informative messages

- data:

  `eeg_data` or `eeg_epochs` object
