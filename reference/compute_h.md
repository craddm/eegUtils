# Compute the h function for two sets of channel locations on the unit sphere.

Compute the h function for two sets of channel locations on the unit
sphere.

## Usage

``` r
compute_h(xyz_coords, xyz_elecs, m = 4, iter = 50)
```

## Arguments

- xyz_coords:

  A set of electrode locations on a unit sphere.

- xyz_elecs:

  A set of electrode locations on a unit sphere.

- m:

  Interpolation constant (higher = less flexible)

- iter:

  iterations for calculations
