# Calculate current source densities

Calculate current source densities

## Usage

``` r
convert_to_csd(data, m = 4, smoothing = 1e-05, scaling = 1)
```

## Arguments

- data:

  `eeg_data` object

- m:

  smoothing constraint (higher = more rigid)

- smoothing:

  lambda constant

- scaling:

  Default scaling (1) is uV / m^2.
