# Check consistency of labels

Internal function for checking 1) whether the labels submitted are a
mixture of hierarchical and non-hierarchical types 2) whether the labels
submitted are present in the data

## Usage

``` r
label_check(cond_labs, data_labs)
```

## Arguments

- cond_labs:

  labels submitted by the user

- data_labs:

  labels from the actual data
